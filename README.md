
# Python Learning Journey 🚀

This repository contains my step-by-step Python learning journey, covering over 50 days of consistent coding practice. Each day is organized in a separate folder with focused concepts, code examples, and exercises.

## 🧠 Topics Covered

- ✅ Python Basics
- ✅ Variables, Data Types, and Operators
- ✅ Conditional Statements & Loops
- ✅ Functions and Recursion
- ✅ String, List, Tuple, Set, Dictionary
- ✅ File Handling
- ✅ Exception Handling
- ✅ Object-Oriented Programming (OOP)
- ✅ Python Exercises & Mini Projects (like Snake Water Gun Game)

## 📂 Folder Structure

Each folder is named as `Day_XX` with the concept or task covered on that day. For example:
- `Day_01`: Introduction to Python
- `Day_17`: For Loop
- `Day_30`: Recursion in Python
- `Day_58`: Constructors in Python

This structure helps track progress and makes it easier for others to follow along.

## 📌 How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/python-learning-journey.git
 

2. Navigate to any `Day_X` folder to explore code for that day.
3. Run the Python files using:

   ```bash
   python filename.py
   ```

## 🛠 Requirements

* Python 3.x installed
* A code editor like VS Code or PyCharm
